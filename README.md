# Customer-behavior-analysis-
Data analytics project showcasing customer behavior analysis using python, SQL and Power BI.
📊 Data Analytics Project

📌 Overview

This project demonstrates a complete end-to-end data analytics workflow, from raw data processing to business insights. It includes data loading, cleaning, exploratory data analysis (EDA), SQL-based querying, dashboard creation, and final reporting.

The goal of this project is to extract meaningful insights from the dataset and present them in a clear, visual, and actionable format.

 📂 Dataset

* The dataset used in this project contains structured data relevant to the problem statement.
* It includes multiple features such as numerical and categorical variables.
* Data was imported and processed using Python.

 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **PostgreSQL** (for querying and data analysis)
* **Power BI** (for dashboard creation)
* **Gamma** (for presentation)
* **Jupyter Notebook** (for development and EDA)

 🔄 Project Workflow

 1. Data Loading

* Imported dataset using Python libraries like Pandas.
* Performed initial inspection of data structure and types.

 2. Data Cleaning

* Handled missing values
* Removed duplicates
* Corrected data types
* Filtered inconsistent or irrelevant data

 3. Exploratory Data Analysis (EDA)

* Analyzed data distributions and relationships
* Used visualizations such as bar charts, histograms, and heatmaps
* Identified trends, patterns, and anomalies

 4. SQL Analysis (PostgreSQL)

* Loaded cleaned data into PostgreSQL database
* Wrote SQL queries to:

  * Aggregate data
  * Perform joins
  * Extract key business insights

 5. Dashboard Creation (Power BI)

* Built an interactive dashboard to visualize:

  * Key performance indicators (KPIs)
  * Trends and comparisons
* Enabled user-friendly filtering and drill-down features

 6. Reporting & Presentation

* Created a detailed report summarizing findings
* Designed a professional presentation using Gamma
* Highlighted insights, conclusions, and recommendations

 📊 Dashboard

The Power BI dashboard provides:

* Interactive visualizations
* Clear representation of key insights
* Easy filtering for better decision-making

 📈 Results & Insights

* Identified key trends and patterns in the dataset
* Derived actionable insights to support decision-making
* Improved understanding of the data through visualization and SQL analysis

 ▶️ How to Run

1. Clone the repository:


   git clone <your-repo-link>

2. Install required Python libraries:

     pip install pandas numpy matplotlib seaborn
   

3. Run the Jupyter Notebook for:

   * Data cleaning
   * EDA

4. Set up PostgreSQL:

   * Import the dataset
   * Run SQL queries provided in the project

5. Open Power BI file:

   * Load dataset
   * Explore dashboard
